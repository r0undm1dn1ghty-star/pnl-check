# P&L Check — коммерческая архитектура

> Open-source → платные уровни. Пользователь open-source = воронка в платный продукт.

## Лестница монетизации

| Уровень | Что входит | Ценность |
|---|---|---|
| **Open source** | Инструкции, шаблоны, стоп-правила, адаптеры (Claude Code, MCP, ChatGPT) | Пользователь может провести диагностику сам → доверие + лидген |
| **Guided Check** | Настройка данных, проверка Evidence Card, разбор результата специалистом | Быстрее корректная исходная картина |
| **Sector Pack** | Отраслевые мосты сверки (проектные, дистрибуция, производство) | Меньше риск применить общую логику не туда |
| **Review Loop** | Регулярная проверка качества, шаблоны брифа, журнал расхождений | Процесс повторяемый, а не разовый |

## Что НЕ продавать

- Не продавай «автономного финансового советника» — это обещание, которое не выполнишь.
- Не продавай PMF/выручку — это прогноз, не evidence-статус.
- Не продавай налоговые/трудовые/юридические рекомендации — это зона специалистов.

## Метрика успеха

Конверсия **оффера → договор**, не «скачали N раз». Отслеживай: скачали → дошли до брифа → запросили Guided Check → купили.

## Позиционирование

> «P&L Check показывает, хватает ли у компании проверенных финансовых данных для конкретного управленческого решения, и что именно нужно сверить, прежде чем действовать.»
