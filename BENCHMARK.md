# Бенчмарк — P&L Check на реальной отчётности

Задача: найти ловушки в отчётности, которые меняют управленческое решение.
Проверено на 3 кейсах публичных компаний FY2025.

## Результат

| Метод | Найдено ловушек |
|---|---|
| Наивный (смотрит только на числа) | 1/3 |
| **P&L Check** | **3/3** |

## Ловушки, которые ловит инструмент

| Ловушка | Реальный случай |
|---|---|
| FCF с субсидиями ≠ операционный | Ростелеком: FCF 37,8 включает субсидии 21,1 |
| Прибыль с разовыми статьями | X5: −13,9% при выручке +18,8% (LTI, обесценение) |
| Прибыль vs денежный поток | убыток при положительном OCF = инвестцикл |

Числа сами по себе не показывают ловушку — её видно только в тексте примечаний.
Наивный метод на числах её пропускает.

## Как воспроизвести

```bash
git clone https://github.com/r0undm1dn1ghty-star/pnl-check
cd pnl-check
echo '{"lines":{"net_profit":94.8},"cash":{"ocf":218.8},"text":"падение из-за LTI и разового обесценения","standard":"IFRS"}' \
  | python integrations/kit/skillkit.py --json
```
