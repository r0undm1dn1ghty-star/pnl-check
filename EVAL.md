# Eval — P&L Check на реальной отчётности FY2025

Разбор проверен на **5 публичных компаниях** по данным МСФО за 2025 год.

## Результаты

| Компания | Уверенность | Ловушки | Сверка прибыль/кэш |
|---|---|---|---|
| МегаФон FY2025 | high | — | направления совпадают — сверка простая |
| Ростелеком FY2025 | high | субсид, субсидии | направления совпадают — сверка простая |
| X5 FY2025 | high | разов, lti, обесцен | направления совпадают — сверка простая |
| Магнит FY2025 | high | обесцен | знаки расходятся: разбирай разовые статьи |
| Ozon FY2025 | high | — | знаки расходятся: разбирай разовые статьи |

## Что учитывает

| Ловушка | Реальный случай, где сработала |
|---|---|
| **FCF с субсидиями ≠ чистый операционный FCF** | Ростелеком: FCF 37,8 млрд включает госсубсидии 21,1; без них ~16,7 |
| **Прибыль с разовыми статьями ≠ операционная** | X5: прибыль −13,9% при выручке +18,8% — LTI-программа и разовое обесценение |
| **Сверка прибыль vs денежный поток** | Ozon и Магнит: убыток при положительном операционном потоке — инвестиционный цикл |
| **Рост финансовых расходов = флаг долга** | МегаФон: финрасходы +78% г/г при операционной прибыли +17,5% |
| Стандарт отчётности | МСФО/РСБУ фиксируется — сверка между стандартами некорректна |
| Уверенность брифа | `high` — P&L и кэш сверены из первоисточников |
| Adversarial self-check | «какой вывод был бы без сверки и чем грозил» |

## Ключевой кейс: X5 — прибыль падает, деньги растут

Без сверки: «выручка +18,8%, прибыль −13,9% → маржа сжимается, избегать».
Со сверкой: OCF +15%, ЧД/EBITDA 0,84х — падение прибыли от разовых статей.
Сверка меняет решение с «продавать» на «разобрать состав падения».

## Границы

- Данные из первоисточников (PDF/XLSX с IR-страниц), примечания к долгу требуют
  отдельного разбора.
- Инструмент не даёт инвестиционных рекомендаций — он строит бриф для решения.
