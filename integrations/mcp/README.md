# MCP-интеграция P&L Check

> Локальный MCP-сервер для проверки структуры и данных P&L. Чистый Python (stdlib), работает без облака и без зависимостей.

## Установка

```bash
# Зависимостей нет — только Python 3.9+
python mcp_server.py
```

## Инструменты

| Инструмент | Описание |
|---|---|
| `validate_pnl_structure` | Проверяет обязательные строки P&L и наличие числовых колонок |
| `check_evidence_levels` | Проверяет, что каждый вывод имеет уровень доказательности (факт/расчёт/гипотеза/догадка/нет данных) |
| `detect_gaps` | Находит недостающие данные для безопасного решения |

## Конфигурация (Claude Desktop / Claude Code / любой MCP-клиент)

Добавьте в MCP-конфиг:

```json
{
  "mcpServers": {
    "pnl-check": {
      "command": "python",
      "args": ["путь/до/integrations/mcp/mcp_server.py"]
    }
  }
}
```

## Проверка вручную (без MCP-клиента)

```bash
echo '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}' | python mcp_server.py
```

## Стоп-правила

Сервер проверяет структуру, но **не** заменяет CFO, бухгалтера или юриста. Значения из таблицы — заявление компании, не подтверждение. Полный набор правил — в `SAFETY_RAILS.md`.
