# Интеграция с Claude Code

## Установка

1. Скопируйте папку `skills/pnl-check/` в свой проект.
2. Добавьте в `CLAUDE.md` проекта ссылку на `AGENTS.md` P&L Check.
3. Запустите Claude Code в папке проекта.

## Использование

```bash
# Запустить P&L Check
claude "Запусти P&L Check. Опросник в templates/context_questionnaire.md, данные в data/"
```

## Что делает агент

1. Читает опросник и структуру P&L.
2. Собирает факты (юрлицо, период, источники, периметр).
3. Сверяет прибыль и деньги.
4. Готовит бриф для решения.

## Стоп-правила

Агент следует `SAFETY_RAILS.md` — не угадывает данные, не даёт налоговых/трудовых/юридических советов, не обещает результат.
