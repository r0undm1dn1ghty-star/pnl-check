# Стандарт доказательств P&L Check (Data Evidence Standard)

> Дисциплина: не выдавать self-report за факт. Каждый вывод опирается на источник.

## Уровни доказательности

| Уровень | Что это | Пример |
|---|---|---|
| **Подтверждено** | Есть первичный источник (выписка, 1С, документ) | Строка P&L сверена с банковской выпиской |
| **Заявлено** | Компания/пользователь утверждает, но нет первички | «Наша маржа 30%» без подтверждения |
| **Расчёт** | Получено из других данных, с явной формулой | LTV = ARPU × retention |
| **Гипотеза** | Предположение, требует проверки | «Снижение ФОТ повысит маржу» |
| **Догадка** | Нет источника, заполнено «на глаз» | «Наверное, налог 6%» |

## Правила

1. **Каждый вывод маркирован уровнем.** Не смешивай «подтверждено» и «догадка».
2. **Self-claim ≠ факт.** Цифра из таблицы — заявление, не подтверждение.
3. **Не повышай уровень без источника.** «Заявлено» не становится «подтверждено» из-за красивого текста.
4. **Недостающие данные → data gap report**, а не выводы.
5. **Платные источники → `paid_source`**, не обходи paywall.

## Что нельзя утверждать без данных

| Утверждение | Что нужно |
|---|---|
| «Компания прибыльна» | Сверенный P&L + движение денег |
| «Маржа X%» | Подтверждённые строки выручки и себестоимости |
| «Долг управляем» | Структура долга + график платежей |
| «Решение безопасно» | Объяснённые расхождения + вопросы менеджменту |

## Ловушки отчётности «Заявлено ≠ Подтверждено» (Рыночный прогон 20.09.2026)

| Ловушка | Как выглядит | Как проверять |
|---|---|---|
| **FCF с субсидиями ≠ чистый операционный FCF** | Ростелеком FY2025: FCF 37,8 млрд включает «государственные субсидии» +21,1 и «проценты полученные» +4,5; без них ~16,7 | Пересчитать FCF без нерыночных поступлений; спросить устойчивость субсидий |
| **Прибыль с разовыми статьями ≠ операционная прибыль** | X5 FY2025: прибыль −13,9% при выручке +18,8% — релиз упоминает LTI-программу и разовое обесценение | Требовать разбивки падения прибыли: разовые vs операционные статьи (примечания) |
| **Стандарт отчётности — обязательное поле** | Сверка «прибыль vs кэш» между РСБУ и МСФО некорректна без поправки | Фиксировать стандарт (РСБУ/МСФО) в карточке данных; сравнивать только внутри одного стандарта |
| **Финансовые расходы ×2 — флаг долга** | МегаФон FY2025: финрасходы +78% г/г (97,3 млрд) при операционной прибыли +17,5% | Проверять структуру долга и ставки в примечаниях до решения |
